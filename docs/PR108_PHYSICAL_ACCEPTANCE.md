# PR108 — Physical Coherent Subwoofer Alignment Acceptance

**Status:** Prepared for hardware commissioning; **no physical acceptance is claimed**.

**Branch:** `feature/pr108-coherent-subwoofer-alignment`  
**Scope:** reference-authenticated Main/Sub timing and polarity proposal → explicit
Apply → fresh measured verification → verified finalization or exact rollback.

PR108 changes physical speaker/Sub delay and Sub polarity only after explicit
commissioning approval. Software tests, synthetic Measurement Lab sessions and
CI cannot establish that a real DAC/ADC/reference path is coherent, that a
microphone is calibrated correctly, or that the resulting acoustic integration
is better in a real room.

Use `PASS`, `FAIL`, `BLOCKED`, or `NOT APPLICABLE` for every row. A
skipped hardware-dependent check is never a pass.

## 1. Required physical topology

PR108 physical commissioning requires all of the following:

- a real Playback System with bass management enabled and one or more mapped
  physical Subs;
- a calibrated measurement microphone on a fixed stand;
- simultaneous microphone + electrical-reference capture on different channels
  of the **same physical ADC/input device**;
- one stable reference signal path used for every Main and Sub leg;
- Main and Sub playback generated from the **same output-device clock domain**;
- a safe line-level reference tap/interface; and
- repeatable microphone geometry covering every commissioned Main/Sub pair.

**Never connect amplifier speaker terminals or another power output directly to
an ADC, microphone input or line input.** Use only a known-safe, appropriately
isolated/attenuated line-level reference path. If such a reference path is not
available, mark coherent physical commissioning **BLOCKED**.

PR108 does not claim independent multi-DAC clock synchronization. If Main and Sub
are generated by devices with unrelated clocks, the current coherent evidence
contract is not sufficient for deployment.

## 2. Before the first alignment sweep

Record:

- exact Git SHA / app build / macOS version;
- selected Playback System and routing signature;
- output and input device identities;
- sample rate;
- Main speaker roles and physical Sub indices;
- bass-management crossover frequency/topology;
- current speaker delay/polarity/trim/EQ and Sub delay/polarity/gain/EQ;
- microphone make/serial and calibration-file identity;
- electrical-reference wiring and interface;
- amplifier, speakers and Sub model(s);
- physical microphone position and distance; and
- original exported Playback System state for independent rollback evidence.

Before any PR108 Apply:

1. Stop ordinary playback and leave the DSP engine idle.
2. Verify that the existing PR106 coherent Measurement Lab route qualifies.
3. Run low-level source isolation: one requested Main or Sub leg must produce
   only the expected acoustic output.
4. Confirm microphone and reference inputs are not clipped and reference SNR is
   comfortably above the configured minimum.
5. Confirm at least three repeat captures per coherent leg qualify with stable
   reference arrival/phase.
6. Do not bypass a blocked reference, route, identity or evidence check.

## 4. Single-Sub commissioning

For one assigned physical Sub:

- capture all intended Main roles against that same Sub;
- PR108 may materialize a negative signed Sub adjustment as one common positive
  delay added to every non-LFE speaker lane;
- a positive signed adjustment is added directly to the physical Sub delay; and
- polarity may toggle only on the physical Sub.

Verify that the measured post-Apply phase delta follows:

```
-2*pi*f*signedRelativeDelay + (polarity toggled ? pi : 0)
```

within the app's configured tolerance.

## 5. Coordinated multi-Sub commissioning

Never commission multiple Subs by running the single-Sub path sequentially.

The coordinated path solves every physical Sub together:

```
C   = max(0, -min(s_i))
D_i = C + s_i
D_i - C = s_i
```

where `C` is the one common non-LFE speaker delay and `D_i` is the
nonnegative delay added to Sub `i`.

Physical acceptance requires fresh verification for **every commissioned
Main × Sub pair**. One failed pair rejects the complete coordinated deployment.
Confirm that the common speaker delay is added once only and that each Sub
retains its independently proposed polarity/delay.

## 6. STOP / FAIL conditions

Immediately stop and roll back where safe if any of the following occurs:

- unexpected acoustic output from a non-target Main/Sub;
- microphone or electrical-reference clipping;
- loss of reference authentication or unstable reference arrival across legs;
- output-device/input-device/sample-rate/routing drift;
- crossover changes between proposal and Apply/verification;
- an Apply changes gain, EQ, crossover, Room Correction, Speaker Optimizer or
  unrelated Playback System state;
- post-Apply phase fails to track the deployed delay/polarity signature;
- aggregate crossover coherence fails the acceptance threshold;
- any included Main/Sub pair materially regresses;
- persisted provenance disagrees with live delay/polarity values;
- rollback overwrites unrelated user edits rather than refusing; or
- audible instability, protection events, severe cancellation or unexpected
  level behavior.

## 7. Practical scope on a conventional passive stereo + line-level Sub rig

A conventional passive L/R speaker pair plus a line-level Sub is a valid PR108
physical target **provided a safe same-ADC electrical reference can be created**.

No individual tweeter/mid/woofer access is required for PR108. Do not alter a
passive speaker's wiring or bypass its crossover for this test.

If the system uses a receiver/integrated amplifier with a variable line-level
Sub/pre-out, that does **not** by itself make the receiver output safe to connect
to an ADC. The reference connection still needs a known-safe line-level capture
topology with correct attenuation/isolation and common-clock provenance.
