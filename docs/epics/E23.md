## Gaps

- G1 [scoped] Moved from E6 G1: the graph-vs-kernel corpus and stereo-chain parity/latency test are partly built in S1, and the kernel is still their only reference for the rest (found in the programme audit; owner slice: S1b).
- G2 [scoped] The stereo-chain latency report is 1 frame short of the measured impulse delay at 44.1 and 88.2 kHz; the kernel measures the same as the graph (owner slice: S1c).
- G3 [scoped] Graph-vs-kernel level difference of up to about 35% on hard-clipped input with compressor, expander, limiter and clipper on; clipping with dynamics on is not yet in the corpora (owner slice: S1c).
- G4 [closed] Closed in S1b: E6 G18 and G25 (double state for the K-weight high-pass, measurement pole, multiband crossover and sidechain high-pass) and E6 G31 (Linkwitz deviation form) are implemented.
- G5 [scoped] The cleanup pass still calls the pair cascade per frame inside the whole-buffer pass; coefficients and state should be hoisted across the frame loop per section. The new bit-identity test compares settled against settled across block sizes and does not isolate the per-sample path; add a test hook (owner slice: S1c).
- G6 [scoped] Loudness match attack and release poles and `smoothToward` remain float at 384 kHz (owner slice: S1c).
- G7 [scoped] No Swift or C test feeds `N60BiquadDesignLinkwitzTransformDeviation` output into the core; add one (owner slice: S1c).
- G8 [scoped] Loudness and multiband parity tests against the float kernel are widened at high rates: peak bound -70, -60, -50 and -40 dBFS by rate band, telemetry tolerance x2 and x4 above 96 kHz, multiband gain reduction 0.03, 0.06 and 0.25 dB, because the kernel's float state error dominates. Tighten when the kernel is deleted (owner slice: S1c).
- G9 [scoped] No idle path: the full chain renders at full cost when the input is silent (found by code reading in the 15 Nov 2026 performance review, not measured; owner slice: S5).
- G10 [scoped] A graph rebuild renders two graphs at once and the host leaves the core's rebuild CPU budget off, so a rebuild on a large layout at a high rate may overload; no bench row covers it (same review; owner slice: S6).
- G11 [scoped] Topology publishes and linear-phase EQ design run synchronously on the main actor (same review; owner slices: S6 for topology publishes, E33 S27 for the linear-phase EQ design, moved 17 Nov 2026 because S27 rewrites that design).
- G12 [scoped] No graceful step-down on CPU overload: the listener hears dropouts and sees a counter only (found by plan and code reading in the 15 Nov 2026 failure review; owner slice: S7).
- G13 [open-question] What the listener hears when another app takes exclusive control of the selected DAC is not known (same review; owner slice: S8).
- G14 [scoped] About 3,000 lines of Swift the app never reaches, about 15 unused types in live files, core functions with no app caller, a misnamed 2,000-line `CoreAudioError.swift` and two SOFA tests that never run (found by static scan in the 15 Nov 2026 codebase audit, not built or run; owner slice: S9).
