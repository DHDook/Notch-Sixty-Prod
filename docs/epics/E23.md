## Slices

### S1 `e23/graph-kernel-parity`: reference corpus before deletion (first slice)

- [~] Graph-vs-kernel full-config corpus: every stage on, all layouts, the eight standard rates (E6 S10 left it open). Built for noise, sweep and impulses in two every-stage configs, and clipping in the linear chain. Ambient is excluded (recorded parity exception of 24 Oct 2026; covered alone in `UnifiedGraphStageParityTests`). Clipping with dynamics on is open as G3 (S1b).
- [~] Stereo-chain parity at all rates with every stage on, and the latency report equals the measured impulse delay (E6 S5 test item). Test built with tolerance 1 frame; the report is 1 frame short of the measured delay at 44.1 and 88.2 kHz (the kernel measures the same as the graph). Open as G2 (S1b).
- [~] Decide double precision for the float biquad and smoothing state the core keeps for kernel bit-parity (E6 G18): measure the 38 Hz K-weight high-pass and 3 s measurement pole at 384 kHz against a double reference before `N60RenderKernel` is deleted. Decision: measured float biquad state error against a double reference (HP 38 Hz / 40 Hz) is about -81 dB at 44.1 kHz, -70 dB at 88.2 and 96 kHz, -63 dB at 176.4 kHz, -62 dB at 192 kHz, -52 dB at 352.8 kHz and -51 to -53 dB at 384 kHz, relative to output. Move the K-weight high-pass, measurement pole, crossover and sidechain high-pass to double state (implementation in S1b).
- [~] Decide double precision for the multiband crossover and sidechain high-pass state at 384 kHz (float biquads kept for kernel bit parity; E6 G25), together with the G18 decision. Decision: double state for the crossover and sidechain high-pass, as recorded under G18 (implementation in S1b).
- [ ] `N60RenderKernel` is not deleted until both are green and S1b (hard dependency of every later slice).
