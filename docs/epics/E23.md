- [x] Decide double precision for the float biquad and smoothing state the core keeps for kernel bit-parity (E6 G18): measure the 38 Hz K-weight high-pass and 3 s measurement pole at 384 kHz against a double reference before `N60RenderKernel` is deleted. Move the K-weight high-pass, measurement pole, crossover and sidechain high-pass to double state (implementation in S1b).
- [x] Decide double precision for the multiband crossover and sidechain high-pass state at 384 kHz (float biquads kept for kernel bit parity; E6 G25), together with the G18 decision. Decision: double state for the crossover and sidechain high-pass, as recorded under G18 (implementation in S1b).
