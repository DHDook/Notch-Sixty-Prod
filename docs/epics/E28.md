## Goal

The Dynamics and Meters pages show a listener what each stage is doing, at display rate, on
every output configuration, with the Equalizer page's feel, precision and accessibility. This is
a system-wide speaker processor, not a mixing plugin: clarity before plugin chrome.

## Design note

1. **Testable cores, thin views.** Plain-Swift types with XCTests: `MeterBallistics`, `ClipLatch`,
   `LoudnessMeter`, `SpectrumDisplayProcessor`, `DynamicsTransferCurve`, `GainReductionHistory`,
   `MeterReadbackHub`, `ParameterScale`, plus the generalised E27 types.
2. **One reader per readback.** `MeterReadbackHub` alone calls the read-and-reset meter and
   gain-reduction readbacks, keeps each subscriber's maximum since its last read, and fans out to
   the Meters page, Dynamics page, navigator and sidebar. It polls only while a subscriber is
   visible (page shown, window not minimised or occluded via `NSWindow.occlusionState`) and
   processing runs.
3. **Drawing.** `Canvas` in `TimelineView(.animation(paused:))`, paused when hidden; data at 60 Hz.
4. **Ballistics.** Peak (instant attack, 20 dB fall in 1.7 s, IEC 60268-18), VU (300 ms to 99 %,
   IEC 60268-17), RMS (300 ms); Peak default, persisted in `PreferenceKeys`. Hold 2 s, then falls.
   The clip latch sets on any over-range sample or true peak above 0 dBTP and clears only on click
   or Reset. Zones use scale ticks, text ("CLIP", "OVER") and a hatched segment, never colour alone.
5. **Accessibility.** Every meter, curve and bar has an identifier and an `accessibilityValue`
   updated at most every 2 s or on latch. Dynamics controls get labels, values with units,
   identifiers and keyboard stepping, as on the Equalizer page.
6. **Loudness (S2).** ITU-R BS.1770-4 K-weighting, derived per rate by bilinear transform of the
   analog pre-filter shelf and RLB high-pass so it matches the published 48 kHz coefficients;
   400 ms blocks with 75 % overlap. Momentary 400 ms, short-term 3 s, integrated with the −70 LUFS
   and −10 LU gates, loudness range per EBU Tech 3342 (3 s windows, −70 LUFS and −20 LU gates,
   10th–95th percentile), presented per EBU R128. True-peak max with hold reuses the engine's 4×
   protection true peak through the hub (no second detector). Swift, on the analysis worker, from
   the existing ring; Output by default, Input optional. Rising `droppedFrames` marks integrated
   "gapped". A folded wider source is measured after the fold, and the card says so.
7. **Spectrum (S3).** Smoothing off, 1/24, 1/12, 1/6, 1/3 octave; averaging fast 125 ms, slow 1 s,
   infinite until reset; tilt 0, 3, 4.5 dB/oct about 1 kHz; freeze; one session-only reference
   trace; hover read-out; Input and Output overlaid. E27 S2b can reuse `SpectrumDisplayProcessor`.
8. **Parameter feel (S4).** Generalise E27 S1's `EQValueParser`, `EQNudge`, `EQEditHistory` and
   `EQNumberField` into unit-aware `ValueParser` (Hz, kHz, ms, s, dB, :1, %, LUFS, phon),
   `ValueNudge`, `EditHistory<State>` and `ParameterNumberField`; the EQ names stay as thin
   wrappers so E27 tests pass unchanged. `ParameterScale` is logarithmic for attack, release, hold
   and sidechain HPF (0 Hz "off" at the left stop), linear elsewhere. Steps: time and frequency
   ×2^(1/12), Shift ×2^(1/3), Option ×2^(1/96); dB 0.5 / 3 / 0.1; ratio ×1.1 / ×1.5 / ×1.02.
   Double-click resets to the config default; Option-drag is 0.1×; values clamp to the config
   range (question 2). Undo stores whole-`DynamicsConfiguration` (before, after) pairs; an outside
   change clears it (as E27 decision 2).
9. **Auto makeup (S4).** Swift only: makeup = −(static curve gain at −18 dBFS input) from
   threshold, ratio and knee (design 10), rounded to 0.1 dB, clamped, written to `makeupGainDB`
   while the toggle is on. Off by default; persisted.
10. **Transfer curve (S5).** Static gain computer with soft knee (Giannoulis, Massberg and Reiss,
    "Digital Dynamic Range Compressor Design", JAES 60(6), 2012) for compressor, multiband bands,
    de-esser, expander (floored at its range) and limiter. A test pins it to the core stage. The
    live dot sits where the curve's reduction equals the readback (unique above threshold); at 0 dB
    no dot is drawn, since there is no detector-level readback.
11. **Gain reduction (S5).** Bars with 1 s hold, a 10 s history (600 points), and a small bar on
    each navigator row with a readback. `UnifiedGraphHost` gains the expander read (an existing
    core readback; no engine change).
12. **Mix, link, hold (S7, core only).** Compressor mix 0–100 % (default 100): mix·wet + (1 − mix)·dry;
    zero latency, so no dry delay (a later lookahead must add one). Stereo link 0–100 % (default 100):
    detector = link·max(group) + (1 − link)·own lane. Expander hold 0–500 ms (default 0): gain holds
    after the detector falls below threshold, then releases; counter round(ms·fs/1000) at snapshot
    build. Mix and link ramp over 5 ms via the mailbox. ABI bump: compressor parameters 10 and 11,
    expander 6. Defaults are bit-identical to today. The frozen kernel is untouched (E27 decision 6).
13. **Realtime (S6, S7).** Document allocation (none on the audio thread), synchronisation
    (snapshot and mailbox only), latency (unchanged), rates (all eight; times in ms), channels
    (1–64 lanes, linked groups) and reset per `docs/REALTIME_RULES.md`. The engine reads no flag;
    no ANC or MIMO path is touched.

## Open questions for the owner

1. **Order.** Recommend E28 after E27 S4 and before E9 (item 4), in written order (S4 after #397).
   Alternative: S1–S3 now between E27 slices, since they share no files with E27.
2. **Ranges.** Recommend sliders keep useful ranges on a log scale, typed entry accepts the full
   config range, and the slider pins at its end beyond it. Alternative: sliders span the config range.
3. **Integrated loudness.** Recommend measuring while the Meters page is visible, pausing (not
   resetting) when hidden, with Reset by button. Alternative: measure whenever processing runs.
4. **Stereo link.** Recommend a 0–100 % amount, default 100 % (today's sound). Alternative: a
   Linked / Independent switch.
5. **Kernel fallback.** Recommend disabling mix, link and hold where the kernel renders, with a
   reason, and leaving the frozen kernel unchanged.
