# Plain wording glossary

User-visible text (screens, errors, the user guide) never names an internal PR number or a lab term. Use these names (E12 S21).

| Replaced term | Plain name |
| --- | --- |
| PR99 A/B/A acoustic verification | A/B/A acoustic verification |
| PR97 hardware setup | Hardware setup |
| PR98 acceptance | Safety acceptance |
| PR100 read-only view | Read-only view |
| PR108 alignment | Crossover alignment |
| PR111 draft | Commissioning draft |
| PR112 acceptance | Hardware acceptance |
| PR92 / PR93 checks | Room geometry checks |
| PR77 / PR78 treatment | Room Treatment |
| PR82 transition | Rack transition |
| PR89 recovery | Level recovery |
| Concurrent HAL clock evidence | Concurrent audio clock evidence |
| HAL clock trace | Audio clock trace |
| Semantic-speaker start | Speaker start |

When a new screen needs a technical term, add its plain name here and use that name in the user guide.
`PlainWordingTests` checks the label and error providers for leftover PR numbers.
